## 機能
- メモの作成、編集、および保存
- キーワードによるメモのフィルター
- ブラウザの IndexedDB ストレージにメモを自動的に保存

## 使い方
1. [webmemo](https://code4fukui.github.io/webmemo/)ページをウェブブラウザで開きます。
2. エディタに新しいメモを入力するか、リストから既存のメモを選択して編集します。
3. メモはブラウザのIndexedDB保存領域に自動的に保存されます。
4. フィルター入力を使って、キーワードでメモを検索します。
